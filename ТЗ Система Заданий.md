Сейчас: в боте есть еженедельные задания. Обновляются они в конце недели автоматически. У каждого пользователя 3 задания, у каждого задания есть прогресс, он заполняется за выполнение разных действий в боте. Когда пользователь заполнил прогресс задания, ему приходит сообщение о выполненном задании и он может единожды забрать награду за выполненное задание.

Нужно: Сделать систему, в которой пользователь сам выбирает себе задания на неделю. У заданий появляется легкая, средняя, сложная версия. Так же добавляется экспа, за наполнение которой (каждые 1000 экспы) выдаётся бесплатный пак. У каждого пользователя свой таймер на выполнение заданий, отчёт начинается с момента выбора заданий. Когда таймер подходит к концу, пользователю приходит сообщение "Время на выполнение заданий истекло, можешь выбрать новые задания на неделю". Пользователю нужно лично заходить забирать награды. Если время истекло и он не забрал награду, он сможет забрать награды, когда будет выбирать новые задания.

ВАЖНО: Таймер для заданий запускается общий. И только тогда, когда пользователь выбрал 4 задания(лимит одноврменно выбранных заданий - 4 любых задания)

## Use cases
### Use Case 01: Выбор заданий пользователем 
Предусловие: Задания на неделю у пользователя не выбраны или время выполнение прошлых истекло

Шаги:

	1. Пользователь заходит во вкладку заданий
		Альтернатива:  Из прошлых заданий пользователь не забрал награды -> сперва забирает награды
	2. Нажимает кнопку "выбрать задания"
	3. На выбор предлагается Н заданий, пользователь может листать влево вправо, смотреть задание. Список заданий составляется по категориям:
			1 задание "Пригласи друга"  
			2 задания из заданий "Коллекции"  
			1 задание "Кинь мячик"  
			4 задания из заданий "5 на 5"
	4. Пользователь выбирает 4 задания, у каждого задания выбирает сложность
	5. Подтверждает выбор

Постусловие: У пользователя появляются задания на неделю, стартует таймер на их выполнение

### Use case 02: Выполнение заданий
Предусловие: Задания на неделю выбраны, таймер не закончился.

Шаги:

	1. Пользователь выполняет действие, связанное с прогрессом задания
	2. Прогресс задания растёт
	3. Когда прогресс доходит до нужного уровня - пользователю приходит сообщение, о том что задание выполнено и он может забрать награду.

### Use case 03: Забрать награду
Предусловие: Задание на неделю выбраны, статус задания "Выполнено".

Шаги:

	1. Пользователь заходит во вкладку заданий
	2. Забирает награду

Постусловие: Статус задания менятся на "Получена награда"

### Use case 04: Получение бесплатного пака

Шаги:

	1. Пользователь забирает награду за задание
	2. Если экспа накапливается > 1000 автоматически выдается пак, пользователю выдаётся сообщение о полученном паке. Экспа передается на следующий пак (Если было 900, взяли 300 -> выдали пак, на новый пак уже 200 экспы есть).
